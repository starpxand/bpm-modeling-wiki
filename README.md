## О проекте

Проектное задание «Моделирование бизнес-процессов» по дисциплине «Современные программные средства».
Для каждой нотации: краткое описание, элементы нотации, правила составления, пример и ссылки на
источники. Все примеры построены на одном общем процессе – обработке заказа в интернет-магазине, –
поэтому нотации легко сравнить между собой.

| Нотация | Что показывает | Пример |
|---|---|---|
| Flow Chart | порядок шагов и решения | блок-схема обработки заказа |
| DFD | потоки и хранилища данных | контекстная диаграмма и уровень 1 (Гейн – Сарсон) |
| RAD | роли и их взаимодействия | клиент – менеджер – склад |
| IDEF | функции, управление, механизмы; сценарии | IDEF0 A-0 и A0, IDEF3 |
| ERD | структура данных | модель «воронья лапка» |
| UML | программная система | деятельность, последовательность, состояния, классы |
| BPMN | сквозной бизнес-процесс | интерактивная модель bpmn-js |

## Запуск

```bash
pip install -r requirements.txt
python tools/build_diagrams.py   # SVG-диаграммы DFD, RAD, IDEF, UML
python tools/build_bpmn.py       # BPMN-модель и её SVG
mkdocs serve                     # http://127.0.0.1:8000
```
